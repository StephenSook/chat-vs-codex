# Shared Chat fixture status

Fixture-only. No partner session or live cross-channel round has been verified.
The live runner does not enable this coordinator, and the judge site makes no
Shared Chat feature claim.

`SharedChatVersus` owns two independent `RoundEngine` instances and requires
separate runtimes and activation clients. An authenticated EventSub adapter must
supply the receiving subscription's channel ID. The official source channel and
source message ID route a viewer's bare `!break` to the other game and deduplicate
the original message and its remote copy in either delivery order. Guesses use
the existing six-family enum and hint-war rule. Free chat text never enters a
repair ticket.

Fixtures cover two simultaneous rounds, independent repairs and rollback, one
combined scoreboard, per-viewer cooldown, bot echoes, invalid source metadata,
hashed provenance, stopped-runner admission and retained asynchronous failures.
Routing receipts are explicitly `shared-chat-fixture`; they do not enter the
viewer season. Fake repair workers in these tests are not live Codex evidence.
The production runtime's existing workspace and hotfix profile remain unchanged.

```sh
VITEST_MAX_WORKERS=1 pnpm exec vitest run packages/round/test/shared-chat.test.ts
```

Before any live enablement, verify both accounts can join a current Stream
Together session, arrange a partner who is live, connect both authenticated
EventSub listeners and isolated production runtimes, then retain a labelled
cross-channel receipt. No partner has been contacted by this build thread.
